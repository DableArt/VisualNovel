# Механика тренировок (мини-ритм-игра)

Ядро механики для тренировок героя: вовремя нажимай стрелки, попадания
анимируют персонажа и качают характеристику (Сила / Ловкость / Интеллект),
три промаха (настраивается) завершают тренировку.

## Архитектура

```
Assets/Scripts/Training/
├── Core/                        ← логика, не зависит от визуала
│   ├── TrainingSession.cs       ← ядро: тайминги, попадания, промахи, события
│   ├── TrainingSessionConfig.cs ← ScriptableObject-настройки вида тренировки
│   ├── TrainingNote.cs          ← одна нота (клавиша + время удара)
│   ├── TrainingHitResult.cs     ← Perfect / Good / Miss
│   ├── TrainingStat.cs          ← Сила / Ловкость / Интеллект
│   ├── HeroStats.cs             ← характеристики героя
│   ├── ITrainingSequenceGenerator.cs      ← стратегия генерации нот (паттерн Strategy)
│   └── RandomTrainingSequenceGenerator.cs ← случайные стрелки
└── View/                        ← визуальная обвязка (Unity)
    ├── TrainingSessionRunner.cs ← обёртка: время, ввод, спавн стрелок
    ├── TrainingNoteView.cs      ← летящая стрелка
    └── TrainingFeedbackView.cs  ← фразы, анимации персонажа, звуки
```

Принципы: ядро (`TrainingSession`) — чистый C#, тестируемо без Unity;
новые виды тренировок добавляются новым конфигом + новыми анимациями,
код не трогаем. Паттерн **Strategy** для генерации последовательностей
(можно сделать паттерны под музыку), события (**Observer**) связывают
ядро с визуалом без жёстких ссылок.

## Настройка в Unity (6000.6.7f1)

1. **Конфиг тренировки**: в окне Project правый клик →
   `Create → VisualNovel → Training → Session Config`. Назови, например,
   `StrengthTraining`. Выстави: `Stat = Strength`, `Max Misses = 3`,
   окна `Perfect/Good`, фразы успеха/промаха. Для Ловкости и Интеллекта
   создай отдельные конфиги.

2. **Сцена** (Canvas в режиме Screen Space):
   - Пустой объект `TrainingSystem` — на него `TrainingSessionRunner` и `HeroStats`.
   - В Canvas создай `NotesContainer` (пустой RectTransform на весь экран).
   - `SpawnPoint` — точка появления стрелок (справа/слева экрана).
   - `HitZone` — зона удара (зелёная рамка на макете).
   - `PhraseText` — TextMeshPro текст по центру («Так держать!»).
   - Объект персонажа с `Animator` (контроллер ниже).
   - `AudioSource` для звуков.
   - На объект `TrainingFeedbackView` привяжи текст, аниматор и звуки.
   - Префаб `NoteView`: Image (стрелка) + компонент `TrainingNoteView`,
     назначь 4 спрайта стрелок.
   - В `TrainingSessionRunner` перетащи все ссылки.

3. **Animator персонажа**: контроллер с триггерами `TrainingSuccess` и
   `TrainingMiss` (имена меняются в инспекторе FeedbackView).
   Переходы: `Any State → Success (trigger TrainingSuccess) → Idle`,
   `Any State → Miss (trigger TrainingMiss) → Idle`. У переходов из
   Any State убери `Can Transition To Self`.

4. **Ввод**: проект уже на новой Input System, ничего включать не нужно.
   Клавиши — стрелки клавиатуры.

5. **Интеграция с новеллой**: из диалога вызови
   `TrainingSessionRunner.StartTraining(config)` через нужную конфигурацию
   (Fungus: `SendMessage` / `InvokeMethod`, Ink: внешняя функция).

## Какие спрайты нарисовать (Ч/Б, манга-стиль)

**Стрелки-ноты (4 шт., 256×256, PNG с прозрачностью):**
- ← ↓ ↑ → — толстый чёрный контур, заливка белая, лёгкая штриховка.
- Отдельно «подсвеченная» версия или рамка зоны удара (квадрат с рваными
  чернильными краями, как мазок тушью).

**Персонаж (посадка — поясной/ростовой портрет, как в новелле):**
- `Idle` — стойка перед тренировкой (1–2 кадра дыхания).
- `Success` — удар/приём: для Силы — удар кулаком со скоростными линиями,
  для Ловкости — уклонение/сальто, для Интеллекта — медитация/книга
  (3–5 кадров на анимацию).
- `Miss` — промах: споткнулся, потёр ушиб, капля пота (манга-эффект) (2–3 кадра).
- Фон: серый градиент + манга-линии скорости (как на макете).

**Эффекты (опционально):**
- Вспышка попадания — «кирябка»/звезда удара тушью.
- Штриховые линии скорости для Success-кадров.

**Звуки (не спрайты, но нужны):**
- `hit.wav` — сухой удар/клёкот; `miss.wav` — глухой шум/скрип.

## Расширение

- Новый вид тренировки = новый `SessionConfig` + новые анимации в Animator.
- Свой ритм (под музыку): реализуй `ITrainingSequenceGenerator` и передай
  его в `TrainingSession` — остальное не меняется.
- Сохранение прогресса: подпишись на `HeroStats.StatChanged`.
